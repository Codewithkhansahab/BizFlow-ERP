# Brand assets

Place your logo image here as `logo.png` (recommended: transparent PNG, ~120–160px width, <100KB).

Development URL used by backend emails (assuming Vite dev server on :5173):
- http://localhost:5173/brand/logo.png

Production URL (after deploy):
- https://<your-domain>/brand/logo.png

Once added, emails will render the logo alongside the app name in the header.
